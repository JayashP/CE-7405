# Design previews (2026-11-18)

Mockups for the user's decision on the input redesign and the colour scheme. They are **not MATLAB screenshots**: the app windows are HTML mockups of the *proposed* layout, rendered with Chromium. The bridge drawings (`bridgeDrawing` primitives), the moment curves and the reaction values come from the real engine (two spans 12 + 15 m, steel EI = 2e9 N·m², 10 kN/m, spec 3-axle truck).

| File | Content |
|---|---|
| `*_app_bridge_*.png` | Bridge model tab: unit system, span table (+/−), support table A/B/C with type drop-downs, one material |
| `*_app_vehicle_*.png` | Vehicle tab: preset, axle table (+/−), direction, reactions per support |
| `*_slide_cover_*.png`, `*_slide_results_*.png` | Slide styles |
| `*_matlab` / `*_sage` | MATLAB-style colours (proposed) / current sage green |

The colour scheme is pending the user's decision; nothing in the app has changed yet.
